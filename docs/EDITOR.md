# Guía editorial — Growth Lab

## Idiomas

Cada documento puede existir en **Español** y **English**. Usa el selector de traducción del Studio para crear la versión hermanada. Publica cada idioma por separado.

## Páginas vs colecciones

- **Páginas** (Home, Nosotros, Metodología…): secciones reordenables con Page Builder.
- **Colecciones** (Servicios, Insights, Casos): plantillas tipadas con campos fijos.

## Publicar un Insight

1. Colecciones → Insights → Create.
2. Completa título, slug, excerpt, cover (con alt) y body.
3. SEO: meta title y description.
4. Publish. El sitio SSR lo mostrará sin redeploy.

## Reordenar Home

1. Páginas → Home.
2. En Sections, arrastra bloques o añade Hero, Logos, FAQ, CTA, etc.
3. Publish.

## Contacto

Los formularios envían email vía Resend. No se guardan leads en base de datos.

## Preview

Con Visual Editing activo en staging, abre Presentation para editar desde la vista previa.
